### 共享文件使用原生附件区域

当前采用用户确认的“原生附件展示＋shared原文件引用”。不通过上传接口另存副本，不建立临时资料工作区。

- 已删除顶部SharedTopicReferences说明区，包括课题、文件数、重新读取状态、返回链接和大段范围说明。
- `useSharedTopicFiles`将选定文件接入ChatComposer/SelectedResources，支持点击预览、移除，以及“文件引用 / 已附预览 / 已读取”状态。悬停可查看相对路径、范围和限制。
- 移除只更新会话后续引用，不删原文件；刷新交接页不会重新恢复已移除文件。
- 同名文件按课题和完整路径区分预览身份。再次点开时刷新原生预览标签页，读取本地最新内容。
- 发送时核对选定内容：新文件或内容变化时最多附前2000字符，未变文件只列身份和路径；正文通过原生`workspace_read`按需分段读取。
- 保留03手动上传附件的source manifest和处理链路。共享引用本身不增加模型预分析调用。
- 记录实际预览与工具读取的时间、指纹、范围、文本及警告。“已附预览”不冒充全文已读，“已读取”也需结合具体范围判断。

共享预览最多30个文件，单文件解析上限15MB、预览解析沿用最多60000字符；实际放入上下文的短预览每份最多2000字符。04全文分析的180000字符合计限制不再套用于03短引用。PDF复用pypdf提取文本，不提供OCR。全部所选正文不可用时该轮失败，部分失败明确记录。

### 生成与网页归档

- `workspace_save`保存模型已经生成的UTF-8 Markdown/文本到本轮`outputs/chat/<session>/<turn>/`，非空、最多1MB、不覆盖，并复用原生文件卡片。
- 点击生成文件卡片，在实际SessionViewerPanel文件预览中可归档；旧文件预览抽屉也接入相同按钮。入口主要适用于原生工作区文件链接及合法outputs生成物，不代表所有正文或文件入口都可归档。
- 用户填写标题、选择研究笔记notes / 实验方案plans / 写作草稿writing，确认授权本次导出；复用原账户策略、路径检查和`export_once`，不重复要求聊天授权卡确认。
- 归档不调用模型，04离线也能完成。保留outputs原件，新建`<目标>/<短标题>-<随机短ID>/归档.md`和`原始文件.<后缀>`，同名或重复归档生成新版本。
- `归档.md`是人工编辑与复用入口。非文本保留附件格式，不用AI转换。来源说明区分生成轮次的选定资料、短预览、实际工具读取和未汇总的回答引用；不编造时间、页码或新颖性证明。
- 成功仅短暂提示“归档成功”，按钮保持“归档”，不常驻显示保存路径。失败保留具体错误，可重试，不需重新调用模型。
- 用户已人工试用并确认看到了网页归档；最新附件展示调整仍交由用户继续试用。
