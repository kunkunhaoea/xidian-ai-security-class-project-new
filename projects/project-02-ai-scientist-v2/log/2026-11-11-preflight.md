# 2026-11-11 · 实验启动检查

正式启动实验前，配置错误常在模型客户端初始化、实验目录创建或论文编译时才暴露。本次为启动脚本增加 `--preflight`，把可以在本机确认的问题汇总到一次检查中。

- 检查选中的想法索引、JSON 结构、实验管理器使用的字段，以及显式指定的初始代码和数据集参考文件。
- 复用树搜索的 OmegaConf 配置结构，额外检查 worker 数量、超时、各阶段迭代上限和模型配置等常用字段。新增 `--config` 供检查和正式运行共用。默认想法路径指向仓库自带样例。
- 按调用阶段判断需要哪些模型凭据。文本和视觉客户端复用检查所用的模型路由。树搜索的 OpenAI 兼容后端读取 `OPENAI_API_KEY`，即使用于 DeepSeek。Bedrock 检查本机凭据配置的迹象和环境变量是否成对设置，实例角色等凭据来源需要运行环境确认。
- 在输出目录或最近存在的父目录创建并立即关闭临时文件，以验证写权限。检查不会创建实验目录。
- 用独立进程探测 PyTorch 和 CUDA。缺少 CUDA 时提示 CPU 回退，PyTorch 无法导入时报错。启用论文生成时检查 `pdflatex`、`bibtex`、`pdftotext` 和 `chktex`。

在项目目录执行以下命令。退出码 `0` 表示本机检查通过，`1` 表示发现错误。凭据值不写入输出。

```bash
python launch_scientist_bfts.py --preflight --skip_writeup --skip_review
python -m unittest discover -s tests -v
```

macOS ARM64、Python 3.12 环境下，30 项离线回归测试全部通过，其中 8 项覆盖本次功能。测试验证了多项错误汇总、配置插值、按阶段检查、凭据值不会出现在输出中、失败退出码和未创建实验目录。真实 CLI 在轻量环境中报告了 PyTorch 探测失败，CUDA 可用和不可用的分支使用替身验证。远程模型权限、Linux GPU 和完整论文流程尚待实机验证。
