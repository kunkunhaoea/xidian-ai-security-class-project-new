# 项目适配层

本目录连接共享课题资料与四个原项目，负责必要的输入输出衔接、项目调用和成果归档。当前仅建立职责目录，尚未实现适配功能。

| 目录 | 对应项目 | 目标 |
| --- | --- | --- |
| intelligence/ | 04 | 将采集资料归入课题，供用户和其他项目使用 |
| deeptutor/ | 03 | 使用选定资料阅读问答，将研究笔记保存回课题 |
| researcher/ | 01 | 接入课题资料，保存科研操作与实验成果 |
| scientist/ | 02 | 接入研究想法与方案，保存实验和写作成果 |

01与02是可选引擎，不要求顺序调用。适配层负责衔接，原项目承担业务；必要修改可放在原项目中，具体实现由负责人确定。

共同目标和协作边界以[总体设计](../docs/workbench-design.md)为准。
